# 북마크 정기 재분류 검증

2026-11-19 KST에 격리 Supabase와 Applemint에서 소유자로 로그인해 설정, 작업 기록, 컬렉션 제안 화면을 확인했다. 검증 앱과 API는 각각 루프백 포트 3011과 55821을 사용했다.

## 회차 종료와 다음 실행

- 11월 18일자 중단 회차에서 **회차 종료**를 열었을 때는 종료 시각이 없었다. **종료 확인** 뒤에는 작업이 `failed`로 마감되고, 남은 한 건에 실패 사유가 저장됐다. 재개 버튼은 사라졌고 기존 `uncertain` 예약은 남았다.
- 종료 직후 설정과 DB는 다음 실행 가능 시각을 11월 20일 09:00 KST로 표시했다. 브라우저 검증에서는 격리 DB의 종료 이력을 하루 앞당겨 날짜 경과를 재현했다. pgTAP에서는 실제 종료 RPC를 실행한 뒤 종료 당일 23:59와 다음 날 09:00을 각각 전달해 등록 여부를 확인했다.
- 14:20 KST에 기존 `applemint-bookmark-worker` cron이 정기 회차 `2493e89d-ff67-4162-a4fe-a381c9243f22`를 등록했다. 새 후보 5건이 모두 완료됐고 이전 회차 후보는 등록되지 않았다. 워커 응답은 HTTP 200, 처리 작업 1건, lease 거부 0건이었다. 실제 OpenRouter 호출 한 건은 `openai/gpt-6-luna`로 기록됐으며 사용액 412,050 nano-USD가 정산됐다.

## 제안 검토와 승인

| 입력 | 제안 목적지 | 검토 뒤 DB 상태 |
| --- | --- | --- |
| 루리웹의 블루 아카이브 글 | 블루 아카이브 | 승인 후 이동 1건, 버전 1 → 2 |
| 맞는 주제가 없는 루리웹 유머 글 | Community / ruliweb | 제안 제외, 버전 1 |
| 맞는 주제와 출처 폴더가 없는 더쿠 글 | Community / etc | 승인 대기, 버전 1 |
| NASA 일반 링크 | etc | 승인 대기, 버전 1 |
| 이미 블루 아카이브에 속한 관련 글 | 제안 없음 | 동일 소속 사유 기록 |

제안 생성 직후와 검토 패널을 연 직후에 소속과 버전이 초기 상태와 일치했고 이동 이력은 0건이었다. 화면에서 한 건을 승인하고 한 건을 제외한 뒤 새로고침했다. 소유자 권한으로 재조회한 결과 승인한 북마크 한 건에만 소속 변경과 이동 이력이 있었다.

브라우저 검증은 `BOOKMARK_LIVE_AI=1`을 지정해 [정기 재분류 시나리오](../../e2e/bookmark-ai.spec.ts)를 실행했다. 인증 설정과 정기 재분류 시나리오를 포함해 2개 테스트가 통과했다. 회차의 날짜 경계와 동시 요청은 [종료 DB 테스트](../../supabase/tests/bookmark-scheduled-classification-controls.test.sql)와 [종료·재개 경합 테스트](../../supabase/tests/bookmark-scheduled-classification-controls-concurrency.test.sql)에서 확인했다.

## 릴리스 검증

Windows 워크트리의 공유 의존성 경로는 개발 서버의 Turbopack 해석 범위를 벗어났다. 브라우저 검증은 동일한 앱 소스를 Webpack으로 실행했다. 표준 `pnpm verify`는 검사 대상 Git 트리 `a03f1e4e248087283dc9d528d9686a37712761c8`를 격리 디렉터리에 내보내고 고정 잠금 파일로 의존성을 설치해 실행했다. Lint, 미사용 코드 검사, DB 생성 타입, Vitest 1,101건, pgTAP 1,043건, Turbopack 프로덕션 빌드와 번들 검사가 통과했다. 검증 Supabase의 보안 advisor에서도 경고가 없었다.

검증과 DB 변경은 로컬 격리 환경에서 수행했다. 운영 적용은 별도다.
